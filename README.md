## 🚀 What I've Built
Most of my code lives in private repositories (client systems and commercial products), so here are the highlights:

- **XMLDownloader** · commercial desktop product · [xmldownloader.com](https://xmldownloader.com)<br>
  Bulk-downloads electronic receipts from the SRI portal and generates Excel reports, kardex and the tax annex (ATS) accepted by the official DIMM validator. .NET 10, WPF + WebView2, ASP.NET Core, SignalR. Own licensing server on Linux and 1,200+ automated tests.
- **Electronic Invoicing Platform** · multi-tenant SaaS<br>
  .NET 8, Clean Architecture, EF Core and SQL Server. XAdES-BES signing with X.509 certificates, SOAP authorization with the SRI, JWT, AES-GCM, 400+ tests and CI on GitHub Actions.
- **Import business systems** · desktop ERP and web costing system<br>
  ERP in C# and SQL Server (imports, multi-warehouse inventory, double kardex, sales, receivables) and an ASP.NET Core MVC system that allocates freight, duties and 20+ expense items across each shipment. Plus a .NET 8 API over the legacy ERP for a React Native + TypeScript sales app.
- **SRI Receipt Reader** · free web tool · [xmlreader.steveen.dev](https://xmlreader.steveen.dev)<br>
  Turns signed and unsigned SRI XML receipts into Excel, entirely in the browser.
